The `serpapi-search-tools` package gives Python agents real-time access to the web, news, maps, images, shopping, YouTube, hotels, flights, and travel search, powered by SerpApi. It natively supports popular SDKs including LangChain, Agno, CrewAI, OpenAI Agents, Pydantic AI, Google ADK, and more.
